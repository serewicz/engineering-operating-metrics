# Contributing

Keep contributions focused on executive-facing engineering operating metrics.

## Workflow

1. Create a feature branch.
2. Keep changes small and reviewable.
3. Run the dashboard in Demo Mode before opening a pull request.
4. Do not commit API keys, GitHub tokens, private repository data, or client data.

## Local Check

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

## Pull Request Notes

Include:

- what changed
- why it matters to CTO or operating-partner users
- how it was tested
