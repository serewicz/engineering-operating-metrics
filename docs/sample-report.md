# Sample Executive Report

## Executive Summary

Engineering delivery is moving, but risk is concentrated in large platform and security changes. Review quality is acceptable, yet rework is visible in several high-impact areas. AI usage cost is modest and should be monitored by team and business area.

## Key Metrics

| Metric | Sample Value |
|---|---:|
| Median cycle time | 29.5 hours |
| Review quality score | 71 / 100 |
| Rework rate | 58% |
| Estimated engineering cost | $23,250 |
| AI usage cost | $116.75 |
| Risk score | 48 / 100 |

## Recommended Actions

- Reduce review queue time by assigning explicit reviewers for platform and security changes.
- Require architecture review for high-risk services and large changes.
- Track AI usage cost by team and business area.
- Use governance flags to identify work missing ownership or linked issue context.

## Board-Level Interpretation

The organization has useful delivery flow, but engineering leadership should focus on reducing rework and making high-risk changes more visible before merge.
